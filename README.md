# AI-Powered Student Expense & Budget Analytics

A beginner-friendly Python data analytics project that explores student spending, displays interactive charts, estimates next-month spending with a simple linear-regression model, and generates budget suggestions.

## Features

- Expense summary metrics: total spend, transaction count, average daily spend, and average spend per month.
- Interactive date-range and category filters.
- Category-wise spending bar chart.
- Monthly spending trend line chart.
- Table of expense records.
- Educational next-month estimate using scikit-learn LinearRegression.
- Rule-based budget suggestions.
- Currency displayed in Indian rupees (INR).

## Dataset

`data/student_expenses.csv` contains **synthetic demo records created for this project**. They are not real student transactions and should not be described as a real-world survey. Columns:

- `date`: transaction date
- `category`: expense category
- `description`: short transaction label
- `amount_inr`: expense amount in rupees
- `payment_method`: illustrative payment method
- `student_id`: demo identifier

For an academic submission, explain that the data is synthetic. If your program requires a real public dataset, replace it with a suitable dataset you are permitted to use and update this section to cite the original source.

## Run locally on Windows (VS Code)

1. Install Python from https://www.python.org/downloads/ and VS Code from https://code.visualstudio.com/.
2. In VS Code, install the Microsoft **Python** extension.
3. Extract this project ZIP and open the `student_expense_budget_analytics` folder in VS Code.
4. Open **Terminal → New Terminal**.
5. Create a virtual environment:

   ```powershell
   py -m venv .venv
   ```

6. Activate it in PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt and run:

   ```bat
   .venv\Scripts\activate.bat
   ```

7. Install packages:

   ```powershell
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

8. Start the dashboard:

   ```powershell
   python -m streamlit run app.py
   ```

9. Streamlit will show a local URL (normally `http://localhost:8501`). Open it in your browser. Keep the terminal running while using the dashboard.

## How the analysis works

1. Pandas reads and cleans the CSV, converts dates and amounts, and creates a month column.
2. Grouping and aggregation calculate spending by category and month.
3. Matplotlib renders the bar chart and monthly trend.
4. Scikit-learn's `LinearRegression` fits a line to historical monthly totals and extrapolates one point ahead.
5. Simple rules produce understandable suggestions based on spending and the budget entered by the user.

## Limitations

- Demo data is synthetic; results do not describe actual students.
- The forecast is a basic educational baseline. A few months of data cannot reliably predict future expenses.
- The budget comparison uses the selected total and entered budget. If the date range spans several months, interpret that comparison carefully.
- Recommendations are rule-based, not generated by a large language model.
- This project does not connect to bank accounts or verify financial information.
